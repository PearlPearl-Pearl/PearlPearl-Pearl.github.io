Featured Project

AIMS Python Autograder

Automated assessment for notebook-based Python programming tutorials

An automated assessment system I'm developing to streamline the evaluation of Python programming tutorials at AIMS Rwanda, where submissions come in as Jupyter notebooks. The tutorials this is built for are still running, and the system is being developed and tested alongside them, with the aim of making assessment more consistent, reproducible, and manageable at scale.
