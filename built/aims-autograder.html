Project

AIMS Python Autograder

Automated assessment for notebook-based Python programming tutorials

In development AIMS Rwanda · 2026

The Problem

Python programming tutorials at AIMS Rwanda are assessed through Jupyter notebook submissions. Grading these by hand doesn't scale well: it's slow, it's easy for standards to drift slightly from one submission (or one grader) to the next, and it's hard to reproduce a grade or revisit how it was reached once the tutorial has moved on. As the tutorials continue, that gap between how much grading is needed and how much time there is to do it carefully keeps growing.

The System

The autograder is a system for automatically assessing Python programming tutorial submissions delivered as Jupyter notebooks. It's being built in parallel with the tutorials it supports, rather than designed upfront and deployed once — so its shape is being pulled directly from real submissions and the edge cases that come with them.
